# 🏥 PharMap — Nöbetçi Eczane Bulma  Uygulaması
# 🏥 PharMap — On-Duty Pharmacy Finder  App

---

## 🇹🇷 Türkçe

PharMap, kullanıcıların bulundukları konuma en yakın ve en hızlı ulaşılabilecek nöbetçi eczaneyi gerçek zamanlı trafik verileriyle bulan bir Android uygulamasıdır.

### ✨ Özellikler
- 📍 GPS konumuna göre nöbetçi eczane arama
- 🚦 TomTom API ile gerçek zamanlı trafik hesaplama
- 🗺️ OpenStreetMap ile canlı harita önizlemesi
- 📞 Eczane telefon numarasına tek tıkla arama
- 🧭 Google Maps ile canlı navigasyon başlatma
- 📌 Sık kullanılan konumları kaydetme
- 🧾 Reçete bilgilerini kaydetme ve yönetme
- 🌙 Koyu / Açık tema desteği
- 🌍 Türkçe / İngilizce dil desteği

### 🛠️ Kullanılan Teknolojiler
- Java (Android)
- TomTom Routing & Search API
- NosyAPI (Nöbetçi Eczane Verisi)
- OpenStreetMap
- OkHttp
- SQLite (Room)
- FusedLocationProvider

### 📲 Kurulum
1. Projeyi klonla: `git clone https://github.com/madmelyzz/PharMap.git`
2. Android Studio'da aç
3. `MainActivity.java` içindeki API anahtarlarını güncelle
4. Çalıştır

---

## 🇬🇧 English

PharMap is an Android application that finds the nearest and fastest on-duty pharmacy based on the user's real-time location and live traffic data.

### ✨ Features
- 📍 Search on-duty pharmacies by GPS location
- 🚦 Real-time traffic calculation with TomTom API
- 🗺️ Live map preview with OpenStreetMap
- 📞 One-tap call to pharmacy
- 🧭 Start live navigation with Google Maps
- 📌 Save frequently used locations
- 🧾 Save and manage prescription information
- 🌙 Dark / Light theme support
- 🌍 Turkish / English language support

### 🛠️ Tech Stack
- Java (Android)
- TomTom Routing & Search API
- NosyAPI (On-Duty Pharmacy Data)
- OpenStreetMap
- OkHttp
- SQLite
- FusedLocationProvider

### 📲 Installation
1. Clone the repo: `git clone https://github.com/madmelyzz/PharMap.git`
2. Open in Android Studio
3. Update API keys in `MainActivity.java`
4. Run the app
